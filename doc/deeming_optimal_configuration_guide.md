# 谛明 (Deeming) 最优配置指南

欢迎使用谛明（Deeming）。谛明是一款强大的本地语音输入工具，通过合理的配置，您可以获得最佳的识别速度、准确率以及流畅的输入体验。本指南基于谛明当前的各项参数设置，为您推荐一套“最优配置方案”。

## 1. 常规设置 (General Settings)

*   **录制快捷键 (Hotkey)**
    *   **推荐配置**：`CapsLock` (默认值)
    *   **理由**：`CapsLock` 键位于左手小指边缘，非常容易触及且不常与其他高频快捷键冲突。谛明支持“短按切换大小写，长按录音”，在不影响正常使用的前提下，极大地提升了操作便利性。

## 2. 语音识别 (Speech Recognition)

*   **ASR 模型选择 (Model Selection)**
    *   **场景A：追求极致响应速度与低资源占用（推荐日常使用）**
        *   **配置**：`FireRedASR2 CTC int8`
    *   **场景B：追求最高识别准确率**
        *   **配置**：`FireRedASR2 AED int8`
    *   **场景C：需要流式在线识别（边说边识别）**
        *   **配置**：`Streaming Paraformer bilingual zh-en`
*   **计算线程数 (Threads)**
    *   **推荐配置**：`auto` (自动)
    *   **理由**：程序会根据您的 CPU 核心数自动分配最优的计算资源，避免资源浪费或卡顿。
*   **音频采集 (Audio Backend)** *[高级隐藏配置，需直接修改 config.json 文件]*
    *   **推荐配置**：`wasapi` (默认优先)
    *   **理由**：WASAPI Shared Mode 提供更低延迟和更高质量的音频采集，仅在初始化失败时回退到 `waveIn`。若发生兼容问题，可通过配置文件手动修改为 `waveIn`。

## 3. 人声检测 (VAD - Voice Activity Detection)

强烈建议开启 VAD，它可以有效去除录音首尾的静音段和噪音，提升最终识别的准确度和速度。

*   **是否启用 VAD (Enable VAD)**：`开启 (true)`
*   **VAD 灵敏度参数 (VAD Parameters)**：
    *   **静音阈值 (vadThreshold)**：`0.15f` (推荐保持默认，适用于大多数环境)
    *   **最小静音长度 (vadMinSilence)**：`500` ms (保证语音停顿不会被误截断)
    *   **最小有效语音 (vadMinSpeech)**：`30` ms (有效过滤短促噪音)
    *   **前置缓冲 (vadPadStart)**：`150` ms (防止句首发音被切断)

## 4. 输出处理与智能润色 (Text Post-processing & LLM)

谛明提供了三种文本处理模式。为了获得最佳体验，**强烈推荐使用“大模型润色 (LLM)”**。

### 方案一：智能大模型润色（最佳体验方案 🌟）

大模型不仅能自动添加标点，还能纠正同音字错误、优化口语化表达，并根据屏幕上下文进行专业词汇感应。

*   **输出处理模式**：`大模型润色`
*   **大模型配置 (LLM Provider)**：
    *   **平台**：`OpenRouter`、`Mistral` 或 `Gemini` (直接使用内置预设)。
    *   **模型推荐**：`qwen/qwen3-4b` 或更强大的模型，如 `qwen/qwen-turbo` 或 `gemini-3.5-flash-lite`（具体视您的 API Key 支持情况而定）。
*   **上下文感应 (Context Awareness)**：
    *   **推荐配置**：`开启 (true)`
    *   **理由**：开启后，谛明会读取您当前输入光标附近的文本作为上下文。这对于编写代码、回复特定邮件或输入专业文档时极其有效，模型会“看”到您正在写什么，从而进行完美的上下文融合和专有名词纠错。

### 方案二：本地自动标点（离线隐私方案 🔒）

如果您完全断网或对隐私要求达到最高级别（不向云端发送任何文本），请使用此方案。

*   **输出处理模式**：`本地标点`
*   **依赖**：需在“模型管理”中下载 `CT-Transformer int8` 模型。
*   **理由**：完全本地运行，在 ASR 识别后自动进行断句和添加标点。

## 5. 高级选项 (Advanced)

*   **强制 Unicode 注入 (Force Unicode Input)** *[高级隐藏配置，需直接修改 config.json 文件]*
    *   **推荐配置**：`关闭 (false)`
    *   **理由**：仅在某些特定老旧软件或特定环境（如无法正常通过剪贴板或标准消息接收文本的窗口）中出现乱码时才需开启。正常情况下程序会自动适配目标窗口。需要修改时，请先彻底退出程序并编辑 `%APPDATA%\Deeming\config.json`。
*   **开启 LLM 审计日志 (Enable LLM Debug)**
    *   **推荐配置**：日常使用`关闭`。
    *   **理由**：开启后会将您的口述文本、捕捉到的屏幕上下文等信息写入本地日志文件，有助于排查大模型提示词效果，但可能会记录敏感信息（API Key 永远不会被记录）。仅在需要调试上下文注入效果时开启。

---

> [!TIP]
> **快速上手总结**
> 1. 打开“设置” -> “模型管理”，下载 `FireRedASR2 CTC int8` 和 `FireRed VAD`。
> 2. 在“智能润色”页配置好您的 LLM API 信息，并开启“上下文感应”。
> 3. 在“语音识别”页开启 VAD，并将输出处理改为“大模型润色”。
> 4. 按住 `CapsLock` 开始高效语音输入！
