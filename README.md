# 谛明·Deeming

> 谛听所思，明达所向。Deem Your Thoughts, Drive Your Way.

谛明是面向 Windows 7 及以上系统的轻量语音输入工具。程序常驻托盘，按住快捷键录音，松开后使用本地模型完成识别，并把结果送到热键按下时绑定的输入位置。一次口述会话依次经历“聆听中...”“识别中...”和可选的“润色中...”三个阶段。

当前版本：`v2.0.0`

## 安全与隐私

> 谛明高度重视用户个人安全与隐私的全面保护：程序不包含任何遥测功能，亦不提供收集个人隐私的在线服务；安装器不会向系统目录或注册表写入与程序运行、维护和卸载无关的冗余资源或残留信息。

安装器只部署运行所需文件、用户选择的快捷方式和 Windows 正常卸载所需登记，卸载时移除这些由安装器管理的内容。语音识别使用本地模型，本地日志不会由谛明自动上传。网络仅用于用户主动触发的模型下载，以及用户自行配置并显式启用的第三方 LLM 文本处理；后者会把请求所需文本和用户启用的有界上下文发送给用户选择的 Provider。

卸载器默认保留 `%APPDATA%\Deeming` 下由用户生成的配置与本地日志；交互式卸载时可勾选“同时删除当前用户的本地数据”，确认后会永久清理这些数据，并在没有其他内容时一并移除安装目录。用户下载到自选目录的模型始终保留，确认不再需要后可手动删除。完整边界见 [安全与隐私说明](PRIVACY.txt)。

## 功能

- 本地语音识别：通过 sherpa-onnx C++ API 运行 FireRedASR2 离线识别，或 Streaming Paraformer 在线流式识别；“在线”指边录音边解码，模型仍在本机运行。
- 按住即说：默认长按 `CapsLock` 录音；短按仍保留系统大小写切换行为。
- 音频采集：优先使用 WASAPI Shared Mode，自动转换为 16 kHz、16-bit、单声道 PCM；初始化失败时使用 `waveIn`。
- 人声检测：使用 FireRed VAD，只保留首尾之间的有效语音。
- 文本后处理：可关闭处理、使用本地 CT-Transformer 标点，或把 ASR 原文直接交给可选 LLM 纠错和润色。
- 上下文感应：显式启用后，可为“感应修饰”提供有界的当前输入上下文，并在请求和投递阶段校验目标身份。
- 原生模型下载：从统一的 Hugging Face 存储逐文件下载，支持断点续传、SHA-256 校验和原子安装。
- 状态提示：托盘图标与 Direct2D/DirectWrite HUD 显示“聆听中...”“识别中...”和“润色中...”等阶段状态；在线、离线识别在“聆听中...”阶段都不展示中间识别文本。

语音识别本身只使用本地模型。网络仅用于用户主动触发的模型下载，以及用户显式配置并启用的 LLM 文本处理。

## 业务流程

1. **绑定输入位置**：按下录音快捷键时记录当前输入窗口和输入位置，并启动音频采集。`CapsLock` 按住超过 300 ms 才确认录音；短按只补发 `CapsLock`，保持系统大小写切换状态。
2. **聆听中**：确认长按后 HUD 显示“聆听中...”。音频采集、可选 VAD 和在线 ASR 分块解码在后台运行，但在线和离线模式都不把 partial 或其他中间识别结果显示到 HUD，也不会在录音期间注入文本。
3. **识别中**：松开快捷键后停止采集，HUD 切换为“识别中...”。离线模式对完整 PCM 执行 VAD 和本地 ASR；在线模式排空流式会话尾部并合并最终 segment。在线会话启动、输入或解码失败时，会自动使用已安装的正式离线模型回退识别。
4. **润色中**：如果输出处理选择了 LLM，识别完成后 HUD 显示“润色中...”，由用户配置的 Provider 对 ASR 原文进行纠错或改写；LLM 默认关闭，失败时回退到 ASR 原文。
5. **投递结果**：结果投递前会再次校验录音开始时绑定的窗口、原生焦点和必要的 UI Automation 输入位置。校验通过后才注入文本；目标或输入位置发生变化时取消投递，不会转投当前前台窗口。

上述阶段均由后台任务执行模型、VAD、网络和文本注入工作，UI 线程只负责状态显示、托盘、热键和消息分发。

## 环境要求

- Windows 7 或更高版本，x64。
- Visual Studio 或 Build Tools，包含 MSVC x64 C++ 工具链和 Windows SDK。
- 约 6 GB 可用磁盘空间，用于下载归档、解压和安装 ASR 与标点模型组合。

仓库已经包含构建所需的头文件、导入库、运行时 DLL 和 bzip2 源码。ASR、VAD 与标点模型均由 Settings 内的模型下载器安装，不随程序或安装包分发。
